# Pirátský poklad

HTML5 slotová hra. Běží offline v prohlížeči a nepotřebuje build.

## Spuštění

Otevřete `demo/index.html` v Chromu.

## Ovládání

- **mezerník** nebo **START** — spin
- **V** — vlna
- **K** — kraken
- **J** — jackpot (MINI / MAJOR / GRAND)
- **F** — free spiny
- **B** — bonus
- **T** — turbo

## Matematika

RTP je cca 96,2 %. Simulátor je v `math/sim.js`.
